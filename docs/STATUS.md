# SketchRoad 完成情况

对照 `docs/PLAN.md`。验证环境：Qt 5.15.2（官方构建，API 限制在 5.14）、`tests/tst_core` 全部通过、`QT_QPA_PLATFORM=offscreen` 截图与矢量 PDF。界面是浅色底加青色 `#117b70`。文书底图是 SVG 路径，填写内容仍是文字。Android 调试 APK 含 `armeabi-v7a` 与 `arm64-v8a`。

图中几何单位是米，Y 轴向上。案例目录名是 `yyyyMMddTHHmmss_` 加 uuid 前 12 位十六进制。
