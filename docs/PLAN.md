# SketchRoad 重构计划（草图版 + 航拍版）

世界坐标单位：**米**（`double`）。旧版 cocos 数据是厘米，导入图符与道路模板时除以 100。Y 轴向上。案例正文不使用旧版 `TufuKind` 整数，对象类型用字符串（`roadline`、`symbol`、`trace`、`debris`、`dimension`、`text`、`crosswalk`、`guide`、`parking`、`compass`），避免 qt-modern 把 kind 6/13/14 映射错位的问题。

图符库仍保留 `legacyKind` 字段，仅作对照，不参与存盘。

数据来自已克隆的 `upstream-src/SketchRoad2dx`（Gitee `qt-accident-visualization` master）与 `upstream-src/qt-modern`。`proj.win32` 构建产物与 `Recon.zip` 未纳入。qt-modern 只作界面参考：其 QML Shape 逐图符渲染、kind 枚举和像素单位模型不沿用。

## 范围

保留：

- 草图版全部现场绘图能力（道路、图符、痕迹、散落物、标注、比例化、文字、指北针、文书、打印）。
- 航拍版在草图能力之上增加：航拍/无人机照片底图、两点标定比例、在照片上绘制、清屏保留底图、按比例导出。

不移植：实景图版、双目、三维重建、经销商（盛航/先森）、高速版、深度、激光雷达、笔录独立版、网络版、注册授权、服务器/FTP、电子签名板、指纹、蓝牙测距仪、AI 模型。比例化仍用手工录入实测值。不迁移旧 plist 案例。

## 架构

- Qt Quick 外壳（触控优先，桌面三栏 / 平板按需面板 / 手机底栏+抽屉）。
- 文档模型与命中、吸附、撤销在 C++。
- 画布是 `QQuickPaintedItem`，用 `QPainter` 绘制。同一套 `paintScene()` 画到屏幕和 `QPdfWriter`。
- 一个案例一个目录：`yyyyMMddTHHmmss_<uuid>`，内含 `case.json`（`QSaveFile` 原子写入）、缩略图、`photos/`、`aerial/`。
- SQLite 索引 + FTS5（中文按字切分）。索引可从目录重建。
- 撤销是命令对象（添加、删除、修改、组合、整场景快照），上限 50 步。自动保存。

## 实现顺序

1. 文档模型、目录与 SQLite、单元测试。
2. 画布（平移缩放、选择、撤销）。
3. 道路模板与手绘车道、图符库。
4. 痕迹、散落物、标注、比例化。
5. 航拍底图与标定。
6. 案例信息、照片、文书与矢量 PDF。
7. 三端界面、示例案例、离屏截图。

## 构建

- qmake：`SketchRoad.pro`。
- 目标套件：Qt 5.14.2，代码不使用 5.15 之后的 API。本机验证用 Qt 5.15.2。
- 测试：`tests/tests.pro`。
